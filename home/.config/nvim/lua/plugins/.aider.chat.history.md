#### why is tailwind's LS not respecting 'clsx'  

The Tailwind CSS language server isn't recognizing `clsx` because `classFunctions` is not a valid configuration option. You need to use `experimental.classRegex` with a regular expression to match class strings within `clsx()` function calls.

Here is the change to fix your configuration:

```lua
lspconfig.lua
```
